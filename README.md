# Plyxl for Mac and Windows

Plyxl for Mac and Windows. Sign in with your Plyxl account and everything is there, plus a launcher on a key from anywhere: **⌥Space** on a Mac, **Ctrl+Space** on Windows. Jump to any app, doc or table, or ask your agent, with the clipboard, a screenshot or a file as context.

### Download
- **Mac** (Apple silicon and Intel): [Plyxl-mac.dmg](https://github.com/Plyxl/plyxl-desktop/releases/latest/download/Plyxl-mac.dmg)
- **Windows** (64-bit): [Plyxl-Setup.exe](https://github.com/Plyxl/plyxl-desktop/releases/latest/download/Plyxl-Setup.exe)

### Installing
**Mac:** open the .dmg and drag Plyxl into Applications. The first time you open it, macOS may say it can't check the app for malicious software. Click **Done**, then go to **System Settings → Privacy & Security** and click **Open Anyway** next to Plyxl. You only need to do this once.

**Windows:** run Plyxl-Setup.exe. If SmartScreen says "Windows protected your PC", click **More info → Run anyway**.

Plyxl updates itself after that.

Every version is on the [releases page](https://github.com/Plyxl/plyxl-desktop/releases). The code is not here.
